description: Crea un commit con un mensaje descriptivo en español
agent: build

Crea un commit con los cambios actuales del proyecto.

Ficheros modificados:

!`git status --short`

Cambios:

!`git diff`

Escribe un mensaje en español que describa **qué** ha cambiado y **por qué**, no una lista de ficheros. Una línea de resumen de menos de 72 caracteres y, si hace falta, un cuerpo breve con el motivo.

Contexto adicional del autor: $ARGUMENTS
